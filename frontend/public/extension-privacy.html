TermoClip privacy, in plain language.

TermoClip reads text only after you click its icon, invoke its translation shortcut, use its selection context menu, or use a save shortcut on Google Translate. It uses that text to translate or save the word pair you requested.

Effective 5 September 2026

What the extension does

The extension translates text you select on the active page and lets you edit or save the result. On Google Translate, it also shows shortcut hints and can save the visible word pair. Access to other pages is temporary and begins only when you click the extension icon, invoke its selected-text shortcut, or choose its selection context-menu action.

Data it handles

  • Website content: text you explicitly select, or the visible source text, translation, and language codes on Google Translate after a save command.
  • Authentication information: the Termorize auth session cookie, read only to authenticate settings, translation, and save requests to termorize.daniil.online.

The extension does not collect browsing history, general activity on other sites, location, financial or health information, or advertising identifiers. Selected text can contain personal content, so translate only text you intend to send.

How the data is used

Selected text and the target language are sent over HTTPS to Termorize. The Termorize server uses Google Cloud Translation to detect the source language and produce the translation. Translation records may be retained so Termorize can serve and reuse results. A word pair is associated with your vocabulary only after you choose to save it.

The authentication cookie remains managed by your browser; the extension does not keep a separate copy. Changing the target language in the extension updates the same language setting used by your Termorize account.

Extension data is not sold, used for advertising or profiling, used to determine creditworthiness, or transferred for purposes unrelated to this feature.

Storage and control

Saved word pairs remain in your active Termorize vocabulary until you delete them. Deleting a pair removes it from the service's active views. Temporary guest accounts expire after seven days. You can stop all extension access at any time by disabling or uninstalling it in your browser.

Security and remote code

Requests to Termorize use HTTPS. All executable extension code is included in the installed package; the extension does not download or execute remote code.

Changes and contact

Material changes will be reflected on this page with a new effective date. For privacy questions or deletion help, open an issue in the Termorize support tracker.
